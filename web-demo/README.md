# 브라우저 단독판

`index.html` 하나로 도는 완결된 게임이다. 서버도 DB도 없이 브라우저 안에서만 돈다.
링크만 열면 바로 한 판 할 수 있다.

## 본 앱과 무엇이 같고 무엇이 다른가

같은 것

- 가격 계산식이 `backend/price_engine.py` 와 같다.
  `base_drift + event_delta + fear_shock + fx_shock` 를 구하고 내 주문량으로 `damp` 를 깎는다
- 공포지수·환율 평균회귀와 목표값 램프 보간이 `backend/index_engine.py` 와 같다
- 공매도 펌프-덤프의 불변 조건(펌프 총합 < 덤프 총합, 복리 순효과 손실, 미끼 가시성)을
  똑같이 강제한다
- 시나리오를 `scenarios/festival_01.json` 에서 그대로 읽어 박는다
- 디자인 토큰은 스펙 14번 값 그대로다

- 결과 분석 다섯 가지가 모두 있다. 원인 분해, 근거별 성적표, 성향 2축 진단,
  군중심리 비교, 공매도 구간 비교

다른 것

- **사람은 나 혼자다.** 실제 행사에서는 참가자 50명이 같은 시장에서 겨루지만
  여기서는 봇 15명과 겨룬다. 다른 사람의 주문이 내 화면의 가격에 영향을 주지 않는다
- 서버, DB, WebSocket, 재접속 복구, 관리자 화면, CSV 내보내기가 없다
- 프로젝터 화면이 없다. 혼자 하는 판에서는 쓸 곳이 없다

## 왜 이 링크로는 50명이 같이 못 하는가

아티팩트가 주는 공유 데이터베이스는 **링크로 들어온 외부 방문자에게 쓰기를 허용하지 않는다.**
실시간 채널도 같은 조직 구성원만 쓸 수 있다. 축제에서 휴대폰으로 들어오는 학생들은
전부 외부 방문자라 주문을 저장할 수 없다.

그리고 스펙 1번이 인터넷 없이 로컬에서 완전히 동작할 것을 요구한다. 50명 대결은
노트북에서 `./run.sh` 로 띄우는 서버 버전이 맡는 일이고, 학교 와이파이 사정을 생각하면
그쪽이 더 안전하기도 하다.

## 다시 만들기

시나리오를 고쳤으면 반드시 다시 돌려야 한다. 안 그러면 체험판만 옛날 시나리오로 돈다.

```bash
./web-demo/build.sh
```

`src/` 안의 조각들을 이어 붙여 `index.html` 을 만든다.

| 파일 | 내용 |
|---|---|
| `src/shell.html` | 제목, 스타일, 골격 |
| `src/engine.js` | 가격·지수·이벤트 엔진과 게임 상태 |
| `src/ui.js` | 화면 렌더링과 차트 |
| `src/result.js` | 결과 분석과 라우팅 |
| `src/scenario.js` | 빌드할 때 생성된다. 직접 고치지 마라 |

## 여는 법

파일을 브라우저로 바로 열면 된다. 폰트만 Google Fonts 에서 받으므로, 완전히 오프라인이면
글꼴이 기본 글꼴로 떨어진다. 행사용 서버 버전은 폰트를 로컬에 번들링해서 이 문제가 없다.
